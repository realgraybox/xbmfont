# Fonts

The headers in this folder are generated by `tools/bdf2xbf.py` from the classic
X11 **misc-fixed** bitmap fonts, in the Unicode (ISO 10646-1) edition maintained
by Markus Kuhn ("ucs-fonts"). Only code points 0x20–0xFF are taken: ASCII and
Latin-1, which covers Danish, German, French, Spanish and the other
Western European languages. The control codes 0x7F–0x9F have no glyphs; the
library draws them, like anything else outside the font, as `?`.

## Licence

The misc-fixed fonts are in the **public domain**. Every source file used here
carries this in its own header:

    COPYRIGHT "Public domain font.  Share and enjoy."

(6x10.bdf says "Public domain terminal emulator font.  Share and enjoy.")
The converter checks this property and refuses a file that does not say
"Public domain", so a font under another licence cannot slip in unnoticed.
Kuhn's README for the collection states that contributed extensions "will
remain in the public domain for everyone's free use".

Nothing needs to be shipped with the generated headers, and there is no
attribution duty. The source file, its checksum and its COPYRIGHT line are
recorded at the top of each header anyway.

## Adding another font

Any monospaced BDF font works. For a font that is not public domain, check its
licence first, then pass the licence text to the converter:

    python3 tools/bdf2xbf.py spleen-8x16.bdf spleen_8x16 fonts/xbf_spleen_8x16.h \
        --license LICENSE-spleen

and keep that licence file next to the header (and do whatever else the licence
asks, e.g. BSD licences want the notice in the documentation of binary
distributions).
